# Featured Projects

## 🚌 Bus Operations Simulator

`React` `TypeScript` `Node.js` `Express` `PostgreSQL` `Vitest` `JWT` `Docker`

A full-stack application modelling real-world bus operations, built around practical workflows from the public transport industry.

The frontend is built with React and TypeScript and communicates with a Node.js/Express REST API backed by PostgreSQL.

### Key Features

- Driver and duty management
- Weekly rota allocation
- Planned absence management
- Daily Sign-On Sheet
- Driver availability and replacement assignments
- Real-time Operations Board
- Incident management
- Operational reports
- JWT authentication and role-based access
- AI-assisted operational recommendations using Gemini
- PostgreSQL relational data model
- Automated business-logic tests
- Docker-based development environment

### Architecture

React + TypeScript → REST API / JWT → Node.js + Express → PostgreSQL
